## 新增回归覆盖

### 滚动与透明分区栏

`LayeredContent` 保持完整滚动视口，通过内容 padding 给首尾元素让位；分区栏独立覆盖真实内容录制层。首页已接入。没有在分区栏下方另切一个矩形滚动窗口，也没有重复录制栏本身造成递归模糊。

新增五项界面测试，实际检查首项初始避让、滑到栏后方、固定栏边界、点击命中与滚动位置、实色回退，以及末项能完全滚出底部遮挡区域。透明尾缘测试用真实像素验证：滚动前后必须出现被滚入的内容颜色，不允许只显示静止背景冒充通透效果。

这不是所有页面已经统一接入的声明；手记和计划完整页面仍未接入。

### 日历

新增六项组件仪器测试。休班角标、日期数字或“今天”头像、事件圆点分别占独立纵向区域。今天继续使用原 `images/companions/cat.webp`，替换日期数字而非叠加。日历保持固定六周网格，切月不因周数变化而突然变高变矮。

日期数字使用实际字形测量，在格子宽度不足时局部适配。边界测试覆盖组件宽度 260 / 280 / 300dp、应用缩放 75% / 95% / 160%、系统字号 1 / 1.5 / 2，共 27 个配置。断言检查数字的语义边界不超出格子、休班角标不与数字相交；不是所有设备的视觉和可读性验收。

还检查了今天不重复显示数字、点击回传精确 LocalDate、1900–2100 月份边界、未知年度不猜测休班、跨年公告日期及随包许可。

### 手记业务层

新增 16 项 JVM 测试覆盖连续输入合并、立即保存、写入途中再次输入、失败重试、版本冲突、恢复草稿的原版本号、无改动不写入、长度超限不截断、取消传播、标题正文心情一致保存、多行格式和 UTF-16 选区。

编辑会话放在应用级仓库中，不依赖某个页面的生命周期。自动保存合并连续输入，不通过取消正在执行的数据库事务实现防抖。提交成功只确认本次写入的文字序号；期间新输入仍需保存。

恢复记录在版本提交之前写入。检测到其他位置已经更新时，拒绝静默覆盖，保留恢复草稿。若恢复记录本身写盘失败，只能保证当前进程内仍保留文字，不能宣称断电或进程被杀后也必然保留。

这些是可供原生编辑器接入的仓库及格式算法；完整编辑界面本轮写入被工具安全检查阻止，没有提交，因此不能声称原生手记编辑已可供用户操作。
