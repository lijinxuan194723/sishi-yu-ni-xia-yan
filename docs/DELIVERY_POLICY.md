# 更新交付记录要求

项目维护者要求每次完成更新，都明确给出版本号以及代码、安装包的位置。

每次交付应列明：实际 versionName 与 versionCode；预览版或正式版性质；基线版本；仓库分支和完整提交 SHA；对应 Actions run/Release；APK 下载文件名和 SHA-256；此次修改摘要、已运行验证和未验证范围。

应用内“版本与更新位置”、package.json 与 AndroidManifest.xml 必须同步。CI 若改写版本/包名，以打包后的 AndroidManifest.xml 为准，不能只读源码推断。安装包名字应包含实际版本号。

在未使用原正式签名且未比较包名、证书和 versionCode 前，不得宣称可覆盖正式版。测试包与正式包的记录不自动互通；签名不匹配时先导出备份，不要求用户直接卸载原应用。

没有构建出 APK 时须明确说明，不把源码 ZIP、补丁或浏览器视频当作安装包。每次版本的详细说明保存在 docs/ 下，保留旧版本追溯信息。
