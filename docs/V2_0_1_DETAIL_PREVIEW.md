# 四时与你 · v2.0.1 细节优化预览

基线：v2.0.0，提交 `2f842bee6b19cf17e6ef2014f36a123adadf32e7`。

这是基于 v2.0.0 的细节补丁，不替换原有首页、人物设定、四季资源、模型接入或备份逻辑，也不修改正式包身份、版本号和签名配置。优化集中在歌曲、书评和情景模拟共用的独立聊天窗口。

## 具体变化

- 会话搜索支持忽略英文大小写、关键词高亮、匹配数量、无结果提示及点击定位；按 60 条分批展示，避免一次展开整个历史列表。
- 消息按需加载较早记录；查看旧消息时不强制拉回底部，增加“回到最新消息”按钮。
- 输入框随内容适度增高，显示字符数；保留 Enter 换行，增加 Ctrl / Command + Enter 发送，避开中文输入法组合输入。
- 修改旧消息前保存原草稿，取消修改后恢复；重发前明确提示后续记录会被替换。发送落盘失败时保留输入内容，不先清空草稿。
- 草稿在输入停顿 280 毫秒后保存；发送、关闭、页面隐藏时立即刷新保存。保存失败与模型网络错误分开显示，并提供对应操作。
- 话题切换使用独立会话实例；停止及关闭时保存已接收到的回复，阻止过期异步回调跨话题写入或重复追加。
- 保留 `luke-topic-chats-v1` 及原有 `{messages,draft}` 格式。读取损坏存档时拒绝覆盖；发现同一话题被其他窗口修改时提示冲突。该保护属于尽力检测，不把 localStorage 当作支持原子事务的数据库。
- 聊天弹窗跟随 visualViewport 的高度与偏移，适配键盘弹出；不覆盖 Android 原有键盘桥接变量。统一气泡、按钮、焦点提示和主题色；尊重减少动态效果设置。
- 增加消息复制与可见反馈。浏览器未允许剪贴板时提示手动复制，不伪报复制成功。

## 验证

已在 Node.js 22.16.0 运行：

```sh
node --experimental-strip-types --test scripts/checks/topic-chat-polish.test.mjs
```

24 项单元测试全部通过，覆盖旧存档读取、坏数据保护、存储容量失败重试、跨话题保存、同话题冲突、重复发送防护、编辑分支、长度限制、中文/英文搜索、特殊字符及 Unicode 高亮。

三个新增或修改的 TypeScript/TSX 文件通过 TypeScript 语法转译检查；语法检查不等于全项目类型检查或真实浏览器测试。

Android 与移动 Web 构建以对应 GitHub Actions 的实际结果为准。尚未完成 Android 真机验收，不能据此声称已通过所有设备兼容性测试。

## 预览包与正式升级

仓库现有 Preview APK 工作流生成的是 `com.luke.summer.preview` 测试包，安装名称为“四时与你·测试”。它与正式版并存，不覆盖正式版，也不自动继承正式版数据。工作流使用预览签名，不是正式升级签名。

本补丁不读取、上传或更换正式签名私钥。正式覆盖升级需要仓库维护者在原有签名环境中构建，保持包名和签名一致，并提高正式 versionCode。请勿为安装预览包而卸载正式版。

## 人工验收清单

1. 春夏秋冬和昼夜模式分别打开歌曲、书评、情景对话，检查文字、按钮及焦点。
2. 320 / 375 / 390 / 768 像素宽度；键盘弹出、收起和横竖屏切换；弹窗输入区可见。
3. 中文输入法选词时不误发送；Ctrl / Command + Enter 只发送一次。
4. 修改旧消息再取消，确认原草稿和后续记录仍在；确定重发后再检查分支。
5. 流式回复期间输入下一句、停止、关闭及切换话题，确认回复不串窗、不重复。
6. 两个窗口同时编辑同一话题，触发冲突后保留本地文本再重新读取；不要自动覆盖另一窗口。
7. 长历史搜索、加载较早消息及返回最新消息；查看旧消息时新回复不抢滚动位置。
8. 模拟 localStorage 容量不足、网络断开及损坏存档，确认错误提示与恢复操作匹配。
