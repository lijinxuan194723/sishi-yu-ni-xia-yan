# 2.0.4 · 专注挂件与聊天章节

版本 2.0.4 / 902009；沿用 com.luke.summer.preview 的包名与签名渠道，覆盖最近交付的 2.0.3。正式 main 与 v2.0.3 Release 不变。

计时移除底部重复说明；新的夏彦头像钥匙挂件只在计时中、当前页面可见时轻摆，停止、后台、出屏或关闭动态效果时停止。动画只变换小挂件，不驱动计时数字、不缩放页面。恢复页面时按开始时间计算真实时长，统计缓存不随每秒时钟重复计算。统计日期使用主题选择器，文字、纸面、钥匙与选项沿用季节颜色。

聊天记忆保留原始消息、旧摘要与固定信息，追加带原文范围和指纹的章节。默认不开启额外模型请求；开启自动整理后，前台聊天空闲时逐段处理，发送或切后台会取消整理。整理失败、被取消、原文或档案发生变化的旧结果不能覆盖现有章节。回复检索相关旧原文与章节，近期原文独立保留；不再先等待一串摘要请求才能回复。重要约定可固定，章节可搜索并定位原文，完整备份包含新章节。

参考思路：Mem0 的追加式记忆 https://github.com/mem0ai/mem0 ，SillyTavern 的摘要与检索分离 https://docs.sillytavern.app/extensions/chat-vectorization/ 及 https://github.com/SillyTavern/SillyTavern ，Risuai 的长期上下文管理 https://github.com/kwaroran/Risuai 。本实现为本机来源关联章节与关键词检索，没有引入这些项目的云服务、SDK 或声称达到其向量检索/基准表现；未复制其代码。自动整理会向用户已配置的模型发送聊天并产生额外调用，摘要准确性取决于模型，不能承诺所有问题都能回忆命中。

本轮不新增 Android 权限。尚未完成的头像上传、可选聊天气泡和字号控制不在此包。已保存数据沿用现有存储，不卸载不清除；安装前保存草稿、导出并确认完整备份。APK 最终身份、摘要、测试覆盖及未通过项以交付资料为准，构建成功不等于 Android 所有设备兼容。

补充检查：滚动到挂件的静态容器，而不是等待永远摆动的子元素静止；保留中间帧断言并检查图片解码。通过实际延迟模型响应检查取消后不写入章节。缓存未改变原文的批次判定，避免搜索章节和编辑固定记忆反复计算整份原文指纹。没有放宽原生崩溃或开屏路径检查。
