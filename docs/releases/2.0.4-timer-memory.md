# 2.0.4 · 专注小动效与分章记忆

Android versionCode 902009。基于已发布 v2.0.3 的 1e5578a7，继续原 com.luke.summer.preview 签名渠道；main 和 v2.0.3 Release 不变。安装前保存编辑内容并导出完整备份，不卸载、不清除数据；签名、包名和实际覆盖测试分别复核，不保证全部厂商与所有数据零风险。

## 计时

删除计时按钮下、专注月历底部的重复说明及提醒区域顶部长段文案。计时盘加入小幅摇摆的夏彦插画钥匙挂件，只动画 transform，不缩放页面、不逐帧改布局。停止计时、挂件离开可见范围、应用进入后台时暂停；减少动态效果时禁用装饰动画。按真实起始时间计算计时，显示刷新和装饰独立。统计计算使用 memo，后台不再保留每秒显示更新。统计日期使用主题日期选择器，计时文字、卡片和强调色继续使用季节变量。

## 长期记忆

新功能已接入真正发送上下文，不是孤立界面。原始聊天、旧摘要和手工固定信息保留。新章节按原文范围追加并带时间和内容指纹；编辑历史后只使用仍有效的章节。自动整理默认关闭，用户开启后空闲整理；使用用户已配置的模型和备用模型，可能产生额外费用，不新接入 Mem0 云服务或上传到另一个记忆平台。

自动单次最多32条、保留12条近期原文，每轮最少12条待整理；手动可整理小批次。45秒超时，自动请求间隔至少60秒，发送聊天或切后台取消。无效或过长结果先验证再保存；过期响应不能覆盖新历史、其他章节或恢复数据。失败不删除原文，不连续自动重试。章节可以搜索、展开、查看来源，完整备份包含新增章节。达到存储/章节上限不自动淘汰旧章。

每次回复组合固定信息、旧摘要、最多3个相关章节、最多5处相关旧用户原文及近期对话。中文检索采用重叠关键词，属于词面检索，不是语义向量检索。原文不会因模型上下文截断被删除，但检索命中、模型理解和摘要正确性不能保证。大量本机记录仍受设备存储和性能限制。本轮未包含之前待办的头像上传、三套可选气泡、全局与聊天字号。
