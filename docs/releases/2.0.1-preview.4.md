# 2.0.1-preview.4 — 主题连续性与夏彦陪伴界面

版本：2.0.1-preview.4；Android versionCode：902004。

## 主题闪烁修正

基线 APK 的本地嵌入式浏览器复测观察到：关闭设置时 root 季节在弹窗退出期间更新，卡片渐变背景瞬时跳变；相册换季移除了全部原照片节点（春季 5 个），图片裁切还读取 root 的 photo-y。翻页控件缺少独立定位，真实指针点击可能被图片/页头挡住。嵌入式复测的存储为模拟对象，不是 Android 运行验证。

本轮采用不透明纯色卡片底面，沿用季节色并以 520ms 连续变色，不通过隐藏卡片/全页截屏掩盖闪烁。根主题等待设置完全退场后再更新；延迟工作在卸载/反向打开时取消。

相册保留按位置标识的节点及图片自身的裁切位置。实际旧图覆盖层解码后才更新相册，选中图片解码后才淡出覆盖；禁用重复的 slide mutation 自动 reInit，显式初始化一次并保留位置。较短相册将位置夹到最后一张，不回到第一张。新图失败保留旧相册。翻页区域独立固定在相册底部，不挡正文，支持真实触摸与键盘。

## 夏彦陪伴感

参考用户提供的角色陪伴/专注/月历截图的层次，而不复制第三方素材、界面、水印。

首页新增“夏彦的工作台”，使用仓库原有夏彦插画、钥匙/相机意象、暖琥珀色细节。每日便笺明确标注为同人创作；没有冒充官方台词、语音或实时模型回复。按钮可直接打开现有专注、手记和聊天，不新增会话记录。

计时页保留原有正计时逻辑，加入陪伴短句、科目快捷按钮、圆润计时盘和花生意象。运行中禁用科目修改；切换页面继续按原 startedAt 计算。未在本轮改变番茄钟/后台通知逻辑。

计时页下方新增专注月历与月度柱图，只从已保存的 focusLog 读取真实日期和分钟数。有记录才显示角色印记，未结束的计时不计入。跨年、闰年及小于一分钟的显示有独立测试。点击日期联动上方统计，保留手动记录修改入口。

## 安全、兼容与验收边界

未改动聊天/手记/专注存储格式、WebView origin、正式包名、网络权限、签名与 CI 工作流。AndroidManifest 只递增版本。

上一预览版存在的 Android WebView 渲染中断不是本轮声明已经修复的问题；最终 Android 结果以本次精确提交的 Motion Verification 为准。不能把浏览器通过当作实体手机验证，不能保证马达手感或全部 WebView 兼容。

新增纯逻辑/源码检查：scripts/checks/companion-theme.test.mjs。
新增实际构建界面检查：scripts/checks/companion_theme_browser.py，由现有完整浏览器流程调用；使用真实指针，记录四季底色中间状态、DOM 身份、图片就绪、相册位置，以及导航/计时保存/月历/窄屏检查。

最终交付应附实际 APK 的版本/包名、SHA-256、证书比对、构建 run、验证 run 与失败边界。不要卸载旧应用，升级前先导出备份；预览包不能覆盖正式版。
