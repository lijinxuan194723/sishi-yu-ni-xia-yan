# 2.0.6 修改与验收清单

工作只保存在 feature/v2.0.6-chat-customization，不合并 main，不发布 Release。本次按使用者最新要求交付源码与本地打包说明，不生成 APK。旧版源码中的日历与计划插画保持原样。

当前阶段：继续实现与验证。下面条目尚不能视为已完成。

1. 我的气泡与夏彦气泡分别选择；短消息内容自适应，不再拉满。
2. 双方独立相册上传与内置头像选择；取消、异常及迁移不覆盖已有设置。
3. 计时插画透明、无底板；原始抠图轮廓不变。
4. 时光手记切换不移动底部导航。
5. 手记寄语整合到唯一顶栏，不再叠加大卡片。
6. 手记移除重复搜索/笔记本入口，保留原有功能。
7. 编辑器底部统一工具栏与透明夏彦元素，键盘、焦点和格式操作检查。
8. 科目初始为空；新增、重命名、删除、校验和备份；删除不破坏历史也不自动复活。
9. 首页、他的此刻、计时采用分区而非长页堆叠，保留全部内容。
10. 音乐和阅读操作收拢；收藏、历史、书架、进度、感想、聊天、外部打开均可达。
11. 移除固定内置书目；动态推荐与历史切换，错误不伪造推荐。
12. 推荐使用相关长期记忆及实际收藏/反馈，尊重共享设置和遗忘；支持偏好更正。
13. 二三级菜单统一尺寸、间距、标题、滚动、返回与按钮；素材来自使用者透明图包。
14. 顶部操作按钮统一视觉和触点，主题与减少动态效果适配。
15. 新素材按需拆分，高清透明；日历和计划插画不更换。
16. 类型检查、生产 Web 构建、数据逻辑与浏览器运行回归、截图人工查看；保留未验证边界。
17. 修正打包元数据和依赖锁文件，不替换依赖版本字符串；提供可复制的打包流程。

验收完成后添加逐项结果与截图。手机帧率、实际模型语义效果和系统相册须与代码/浏览器验证区分，不作无依据保证。
