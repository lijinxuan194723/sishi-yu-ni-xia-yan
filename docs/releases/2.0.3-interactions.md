# 2.0.3 · 交互细节

版本 2.0.3，Android versionCode 902008。以 d4a09dd2 的 2.0.2 为基础，同一分支和签名渠道；main 不变。

设置目录保留本次搜索、返回位置和焦点；空搜索结果提供清除入口；Escape 按层返回。模型与天气未提交表单在应用进程内暂存，切换子页或关闭设置后可接着填写，并可撤销本次修改。暂存不等于保存：强制结束进程后会消失，离开后超过30分钟未使用的草稿过期，不额外把密钥草稿写入磁盘。只有保存按钮应用配置。已保存的配置改变时不套用旧草稿。

连接测试和定位可以取消；编辑输入会取消旧请求，避免晚到的结果覆盖新输入。测试20秒超时后解锁，不自动重复请求。天气保存调用独立天气接口，不重写模型配置。

日期支持八位数字、斜线与全角数字输入；闰日和范围照常校验。年份可清空再填，年月限制在允许范围。日期支持方向键、Home/End、PageUp/PageDown，Shift配合翻页可跨年。按钮区固定，日历单独滚动，关闭后焦点回到原入口。操作面板退出期间不能重复提交，手记移动和回收站确认有明确返回入口。

没有新增 Android 权限、依赖或存储格式迁移。聊天原文、原记忆实现、笔记和原生开屏未改动；此前要求的头像上传、可选气泡、字号控制及章节式记忆不在本轮交付范围。

检查分别报告逻辑、APK内Web界面和Android运行情况，不把编译成功等同于完整验收。连接取消检查使用隔离的本地模拟响应，不使用真实模型密钥；实体手机、第三方客户端和长期运行仍需独立验证。保留既有启动兼容性失败，不以改变断言掩盖问题。

交互 API 参考：Base UI Dialog 官方文档 https://base-ui.com/react/components/dialog （initialFocus/finalFocus、嵌套弹窗和退出完成回调）。
