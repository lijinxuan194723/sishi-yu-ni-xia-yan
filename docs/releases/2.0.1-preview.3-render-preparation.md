# 2.0.1-preview.3 绘制准备补充

页面改为在不透明原生保护层下面正常绘制，不再启用额外耗内存的 offscreen preraster。保持 postVisualStateCallback 及真实绘制帧门槛；屏幕阅读器在开屏完成前不会访问尚被遮挡的主页内容，只有最后的保护层移除时恢复可访问性。

这是一项绘制与无障碍改进，不是已证明解决旧版 WebView 渲染进程异常的结论。之前在 API30 / AOSP WebView128 / x86 软件模拟器中的 SIGTRAP、SIGSEGV 失败仍保留。新候选仍须重新做同一 APK 的构建、浏览器、API30/35、四季录屏和异常恢复检查。没有改变 WebView 版本、减少测试平台、跳过错误或启用自动恢复循环。

版本维持未交付的 2.0.1-preview.3 / 902003。main、签名、应用数据和网络权限不变。
