# 2.0.2 · 设置与主题日历

版本 2.0.2 / Android versionCode 902007。基于 14bb9989 的原包名和签名渠道，继续覆盖先前同签名的 com.luke.summer.preview 应用；不替换正式 com.luke.summer。桌面显示名为“四时与你”。

本次范围是设置和日期界面：设置按日常与外观、聊天与记忆、数据与权限分组，支持搜索和子页返回；模型与天气表单分开。首页删除重复生日礼物按钮，生日入口保留在设置和纪念日卡片。日期弹窗随主题改变颜色，支持输入日期、年月选择、确认取消、今天与键盘导航；聊天日期筛选、生日和相伴日期采用该组件。一起计划新增指定日期跳转及 2026 中国大陆休/班标记，来源为国务院办公厅 2025-11-04 公布的安排；未收录年份不推断官方调休。

移除可见预览字样及生日、计时底部冗长提示。保留系统时钟最终确认、原有按钮触感和动画减少设置。无新增 Android 权限。

本次不包含尚未完成的可选气泡、头像上传、全局/聊天字号、新章节式记忆。旧记忆整理、全部聊天和备份结构不变。新增界面不等于所有兼容性问题已解决；此前 WebView 渲染进程问题和不同手机动画帧率仍需独立验证。

逻辑检查、签名 APK 对应的浏览器检查与 Android 运行检查分别记录，失败或中断不能算通过。精确提交、构建任务、APK 校验值和实际测试结果放在交付说明。安装前先导出完整备份，不卸载、不清除数据。
