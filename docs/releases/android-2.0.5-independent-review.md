## 安装说明

本次先交付供查看当前效果的独立体验包，桌面名称为 **四时与你·体验**，包名为 `com.luke.summer.review205`。它与原来的 2.0.4 并存，不覆盖旧应用，不自动读取或共享旧应用的数据。**不要卸载 2.0.4，也不要清除旧应用的数据。**

直接安装即可查看界面。需要使用旧聊天试用时，先在旧版导出完整备份、确认文件已保存，再在体验包中导入；保留原应用与备份。备份不包含模型 API Key，体验包需要重新填写模型连接。当前未为此独立分支配置原版签名凭据，因此本文件不是原应用的覆盖升级包，也不承诺后续体验包可覆盖本包。重要内容仍应另行备份。

## 自动记忆的工作条件

自动整理默认启用，旧配置迁移时补上自动更新标记。完成的新对话空闲后分批处理；原始聊天保留在持久化存储，整理结果进入章节摘要和事实集合；普通回复带入近期上下文、已提取事实和相关旧片段，而非把所有原文一直塞进同一模型上下文。

实际运行测试验证了：不手动触发也会启动；模拟失败后重启自动重试并保留进度；新对话完成追加章节但不删除原文；回复请求包含已提取记忆；手动停用取消正在执行的任务；迟到结果不覆盖新设置和进度。模型响应是受控测试接口，不能代替真实服务商跨天、多话题的长期体验验证。

需要有效的模型地址、模型名称和 Key，应用处于前台且联网。系统结束进程或强行停止后不会继续执行，重新打开会补处理。整理额外调用所配置的模型 API，可能计费。当前相关记忆召回主要是文字相关性评分，不是经过长期验证的向量语义服务；原文引用检查也不能保证模型概括永远准确，手动更正、固定、忘记仍有必要。

原文不会因上下文变长而主动丢弃，但本地存储不是无限或永久保障；卸载、清除数据、设备损坏及空间耗尽仍影响数据，完整备份应保留在应用之外。
