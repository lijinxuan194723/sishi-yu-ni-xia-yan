# preview.3 · 渲染故障恢复与连续采集

验证 #16 的 Android 11 在第一组季节冷启动通过后，WebView 128 的沙盒渲染进程发生 SIGSEGV；由于应用未接管 onRenderProcessGone，宿主随之退出。Android 15 则因临时 UiAutomation 进程抛出 Bad file descriptor 中断验证。两者的失败结果与日志保留，不归为同一种故障，也不当作通过。

应用补充原生渲染终止处理：取消开屏监听与过期回调，移除并销毁失效 WebView，切断旧请求，不复用旧视图。显示可滚动的圆角恢复卡片，明确已保存记录保留、未保存输入可能丢失；用户可选择重新载入或返回桌面，不自动反复刷新。正常操作路径没有测试后门、调试桥接或新权限。

测试改用独立 APK 中持久的只读 UiAutomation：不反复销毁 UIAutomation 连接。原有真实触摸和 8 组四季昼夜断言不放宽，额外捕获 native fatal signal 及渲染终止日志。观察器仅绑定模拟器 loopback，经 ADB 转发读取界面树；不进入交付 APK。测试环境构建临时签名观察器，与应用签名无关。

测试结尾在隔离模拟器中，验证唯一沙盒渲染进程后定点终止它，检查宿主不退出、手动重载、不自动循环、返回前台和原测试笔记保留。这一故障注入需要 rootable 测试镜像，绝不要求用户设备 root。对正常交互中出现的任何故障仍判失败。恢复入口提高容错，不宣称修复了所有 WebView 引擎内部问题。

版本继续 2.0.1-preview.3 / 902003，此候选此前没有交付 APK。最终验收结果以相同提交和签名安装包的日志、录屏与哈希为准。
