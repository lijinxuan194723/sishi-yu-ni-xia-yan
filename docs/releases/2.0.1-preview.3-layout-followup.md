# preview.3 交付前布局复查

生日卡片的滚动容器与关闭控件分离：初始焦点放在首个关闭按钮，长内容只滚动内部 birthday-scroll。横屏、26px 正文和44px标题也不能将关闭按钮带出屏幕。返回桥接继续通过同一关闭逻辑，预览退出后回到生日设置。

较矮的横屏侧栏支持独立滚动，不再将底部的计时导航留在视口外。每次页面切换只更新右侧操作按钮组的元素身份，避免部分 WebView 保留此前页面隐藏按钮的可访问性状态；聊天、手记等页面状态不因此重建。

保留之前发现问题的失败记录。新增真实指针点击、滚动后关闭键位置、系统返回桥接、模态遮罩清理等回归项。最终结论以同一提交的构建与运行结果为准，不将仅通过的旧构建冒充最终验证。
