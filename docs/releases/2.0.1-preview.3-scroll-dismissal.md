# 2.0.1-preview.3 · 滚动设置关闭修复

基线提交 3732747dc8761f93dcd89b470967458698146a9d。继续候选 versionName 2.0.1-preview.3 / versionCode 902003；此前未交付该版本的 APK。

Android 11、15 的失败截图均证实：外观页滚动到光照和触感选项时，原绝对定位关闭按钮随内容移出屏幕。不是通过放宽测试或滚回页顶解决。本轮在原弹窗焦点范围内加入零高度 sticky 锚点，把同一关闭按钮保持在可见右上角；其他弹窗使用 display:contents 保持原布局。增加圆形背景和边框，避免滚动文字降低按钮辨识度；标题和说明预留关闭区域。

新增浏览器检查覆盖 360×592、320×568、844×390、390×300，包含正常和减少动态效果、真实滚轮、半程/底部几何及 elementFromPoint 命中检查。最后以原始鼠标坐标关闭，禁止依赖自动滚动使断言通过。Android 的八次季节×昼夜冷启动、生日返回设置、触感关闭/单次调用等检查保持原验收条件。
