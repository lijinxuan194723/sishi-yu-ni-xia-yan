# 2.0.1-preview.3 开屏交接补充

逐帧检查旧候选（5f4e76e8、0081a409）的 Android 15 春季白天录屏，发现绿色占位屏先露出、圆章随后重新出现。此前仅有动画回调和功能检查不能发现这一问题。

本次不阻断 Activity 的首次绘制，允许系统及时交接 SplashScreen 表面；页面准备完成只控制退出，底下原生圆章保护层保留到系统淡出即将开始。页面颜色在 React 发布就绪状态前同步原生，删除 HTML 和原生的固定绿色占位色。使用同一段淡出，不另播第二次入场。

补充实际录屏像素检查：不插帧、不改变时间轴，解码全部帧；排除系统栏后，超过九成画面为旧绿色占位色则失败。历史缺陷录屏已确认能被该检查拒绝。此检查针对已知绿屏回归，不等价于证明所有设备的帧率或全部视觉质量。

继续使用候选版本 2.0.1-preview.3 / 902003，未交付前不另占新版本号。main、签名、网络权限、存档格式均不改变。完整构建、浏览器、Android 11/15 及异常恢复仍须重新验收。历史 Android 11 WebView 128 渲染进程意外终止记录保留，不将重试或自动恢复当成故障消失。
