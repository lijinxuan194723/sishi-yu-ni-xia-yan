# 2.0.1-preview.2 连续动效 · 验收补充

本轮继续基于 fix/rounded-native-startup，保留 versionName 2.0.1-preview.2 / versionCode 902002。此前该候选版本未向用户交付；正式版 main 不变。

## 修复

实际 Android 11 故障不是简单的关闭按钮定位错误。减少动态效果规则把 Dialog 的 translate 设为了 none，移除了 Tailwind 用于弹窗居中的位置偏移，导致窗口右下偏移，关闭控件出屏。现只关闭动态效果，不清除弹窗定位。

通用对话框关闭按钮增加明确的无障碍名称和至少 44 CSS 像素的点击区域。独立话题窗口同步该尺寸，并给标题留出空间，避免长标题与关闭键重叠。

## 验证增量

- 浏览器新增 320×568、390×844、844×390 的减少动态效果几何和真实点击检查。
- 增加独立话题关闭触控区域校验。
- 补测书籍编辑取消、推荐收藏/历史、生日祝福的真实中间状态、退出透明后卸载和返回页面；测试取消不会写入书籍。
- Android 检查关闭按钮必须有可见 bounds，再用真实触摸关闭。
- 模拟器预检与应用测试分开：仅在应用启动前，允许一次明确记录的 Pixel Launcher 系统故障恢复。应用测试中的故障不会被关闭、跳过或当成通过。

此前 0ea1fc7 的 Android 11、15 运行检查均通过；后续候选必须重新运行完整工作流，不使用旧结果代替当前构建验收。最终 APK 和验证 run、完整提交、哈希与证书比较结果由交付说明记录。

屏幕录制像素分析用于确认实际画面有连续混合状态，而非只看动画回调；软件渲染模拟器的耗时不能当成真机 FPS。覆盖到的测试通过不等于保证每一种手机、旧 WebView、网络和接口配置都没有问题。
