# 2.0.4 / 902009 · 计时与聊天章节

本轮延续 com.luke.summer.preview 包名和原签名渠道，正式 main 与 v2.0.3 Release 不改动。交付以最终 APK 的版本、签名和校验值为准。

计时页去除重复的底部文字，增加夏彦小挂件。仅在计时运行且可见时轻摆，切换页面、后台、关闭季节动画或减少动态效果时停止装饰。计时数据与装饰动画分离，日期筛选沿用主题日期组件。

长期聊天记忆增加原文范围可追溯的追加章节、固定信息和相关旧原文检索。原聊天、旧摘要和固定信息保留，自动整理默认关闭，需用户确认使用已经配置的模型。空闲整理可取消；每次写入核对原文指纹和档案版本，修改、恢复或取消后的过期结果不得覆盖数据。词法检索并非向量检索，不能保证所有提问都命中或模型永不忘记。参考 mem0、SillyTavern 和 Risuai 的分层存储、摘要和按需召回思路，不复制或集成其服务。

清除源文件内的共享模型凭据。已有本机保存的主、备用模型继续保留；不再静默添加其他服务的备用配置。未配置的新安装需填写自己的模型服务。此前随代码发布的凭据应由账户持有人轮换；本轮不代替用户执行凭据撤销。测试仅使用虚构密钥及隔离响应，禁止自动测试访问真实 HTTPS 服务。

本轮的 Android 恢复测试纠正了重入方式：从桌面使用 MAIN/LAUNCHER 和任务复用标志返回原 Activity，而不是用默认 am start 新建页面。全部故障注入、保留数据、开屏和减少动画断言保持不变。Android 11 曾出现实际 WebView 渲染中断，不因修正测试方式而宣称已修复。

实际编译、浏览器、Android 和签名结果分开记录；模拟模型仅验证编排和存储，不验证真实模型摘要质量。头像上传、可选气泡和字号设置尚未纳入本轮。无新增 Android 权限。安装前先导出备份，不卸载、不清除数据。
