# WebView 2.0.10 hotfix.3 · 指针与计时排版修复

源码批次 `hotfix.3-visible-clock-hands`，Android versionCode `902063`。直接基于本轮上传的 `Four-Seasons-Luke-WebView-2.0.10-hotfix2-source.zip`，SHA-256 `5077565f16fe61a5df62d8dbc49b0ed466e1130a1dff05e3127c6002292eec9c`。不是换回旧 GitHub 基线，也没有修改原生 Compose 工程。

## 复现结果

上一版专注表盘里的活动图形是外围小三角，中央仍是数字和人物，并不具备从表心伸出的分针、秒针。提醒页只有数字与拖尺，没有钟面。源码重新构建的资源文件名与已上传 hotfix.2 APK 中的资源一致；`reports/baseline-reproduction.json` 保存了当时的形状和提醒页无表盘记录。

这次将指针本身更换为完整表针，不再用外圈的小标记冒充指针。没有只调整「动画开启」状态后就宣布修复。

## 实际改动

| 部分 | 当前行为 |
|---|---|
| 专注表盘 | 分针和暖色秒针从同一表心伸出，外沿进度为辅助；数字、人像和说明移到钟面外。所有旋转均使用 SVG `(100,100)`，并明确 CSS origin 为 `(0,0)`，避免默认50%偏移叠加第二个中心。 |
| 真实时间与动画 | 每帧从原 `startedAt` / `endsAt` 采样，不以帧数累加时间。切页、后台或不可见时取消绘制；返回直接显示当前时间，不重播遗漏帧。 |
| 减少动态效果 | 关闭季节动效或系统减少动态效果时，装饰停用，功能性指针仍按每秒一跳更新，不冻结真正的时钟。 |
| 提醒页 | 未启动倒计时时显示设备当前时、分、秒；开始后换成剩余时间指针；暂停时针与数字一起停住，继续后一起恢复；重置后回到当前时钟。开始/暂停与重置按钮等高对齐。 |
| 更改暂停的分钟数 | 显示「按新时长开始」，明确重新开始所选分钟；不再一边显示新分钟、一边偷偷续走旧剩余时间。 |
| 番茄页 | 接入同一个指针引擎；将开始／暂停与重置放到钟面下方，尺寸对齐；时长和分类放进可展开区域，保留全部配置与原阶段逻辑。 |
| 矮屏与大字号 | 专注钟面与读数并排布局；常规高度则使用大钟面、下置读数。主要开始／保存按钮独立于滚动内容，48组尺寸/字号组合均完整可点。 |
| 统计与月历 | 统计日期改用紧凑的完整单行格式，防止年份、月、日随机拆行；专注月历标题精简并保留完整无障碍名称，月份操作与标题分开。 |
| 系统提醒 | 仍在提醒页下方「系统闹钟与锁屏提醒」里，点开即可使用原确认入口。不能打开系统时钟的浏览器显示原因，而不是静默留下不能点的按钮。 |

停表和暂停时指针静止是有意的；不会为了「看上去在动」让未启动的学习时间增加。提醒页未启动时显示的是当前时间，不是已经启动的倒计时。
