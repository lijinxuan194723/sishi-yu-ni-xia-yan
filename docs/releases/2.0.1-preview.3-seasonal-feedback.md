# 2.0.1-preview.3 · 四季开屏、生日卡片与触感

基线：已交付的 2.0.1-preview.2 / a9f1d27251446460d181aa52eff8e6de0dc3a96f。
候选 Android versionCode：902003。分支 fix/rounded-native-startup；main 不变。

## 本次实现

原生开屏按应用保存的季节与光照偏好选择四季圆章和八套昼夜配色。自动季节每次启动依据当地月份重新选择；手动季节优先。系统最早的启动帧可能使用上次缓存主题；应用接管后在同一原生表面交叉衔接，不增播第二个全屏开屏。首次升级需要读取已有外观设置后同步原生缓存。

生日祝福等待原生开屏退出后出现；生日预览与设置按退出完成回调顺序切换，不叠加两个焦点锁。圆角祝福卡支持滚动、大字体、横屏及随时关闭。12 个单次装饰替代无限庆祝循环。预览不设置当天已读；真正的生日关闭后记住当天。存储错误不能阻止关闭。

按钮轻点、选项切换和确认使用 Android 原生触感；可在设置关闭。网页捕获真实点击、原生侧双重节流；自动点击、禁用按钮、退出中的层与后台保持静默。没有绕过系统触感设置，没有新增振动权限或循环振动。实体马达的主观手感不能由模拟器测试证明。

相关按钮的圆角、44px 操作面积及焦点样式统一；按压使用独立 scale，不覆盖用于定位的 transform。

## 验证与交付

保留既有细节、逐帧浏览器及 Android 冷启动测试；补充季节月份逻辑、四季日夜资源、生日单层切换、存储已读、减少动态效果、触感开关与真实原生点击路由。Android 新增四季各昼夜冷启动及录屏，覆盖升级基线改为上一交付 preview.2。

最终是否通过以同一提交的 Preview APK 与 Motion Verification 结果为准。最终交付附实际 APK versionName/versionCode、SHA-256、证书比较、测试范围与未验证事项；失败候选不作为验收通过版本交付。
