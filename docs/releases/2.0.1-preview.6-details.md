# 2.0.1-preview.6 · 返回衔接与手记细节

候选版本 2.0.1-preview.6 / 902006，基于最后交付的 preview.4，整合此前未发包的 preview.5 代码。代码位于 fix/rounded-native-startup，正式 main 不变。最终以签名 APK 内实际版本为准。

## 返回衔接

快速退出再进入有时在 onStop 之前就触发 onResume。现使用暂停/恢复配对判定，使用独立的轻量圆章淡出，不重建 WebView、不重新载入页面、不缩放正文。从音乐、系统时钟、文件选择器及权限界面返回不重复播，系统关闭动画时直接恢复。

慢帧测试发现固定的清理计时器可能与淡出开始同时执行，造成一帧移除。返回过渡现按实际绘制节奏推进，正常节奏为 280ms，每次进度最大推进32ms。页面绘制回调和120ms回退均可启动；650ms仅清理不能开始的过渡，不抢先中断已启动的动画。暂停、离开、销毁、渲染进程终止会及时取消。覆盖层不拦截触摸；这不保证所有硬件的帧率或忙碌设备的墙钟耗时。

主题图片解码复用；同一分钟、同一主题和光照设置不重复发布页面状态，避免 focus 和 visibilitychange 同时触发重复的大图准备和重新渲染。

## 手记

手记由一排小图标改为圆角操作面板。短按编辑，480ms长按或可见的更多按钮整理。手指移动、滚动、取消、切后台会取消未触发的长按。长按后的释放点击在按钮操作和全局触感之前消耗，不影响下一次手势或键盘操作。

面板支持置顶、加星、移动、复制、导出、多选；回收站独立且需要确认，不是永久删除。列表节点稳定、正文两行摘要、元信息单独排版。压缩装饰头部，编辑器标题与正文分区，真实保存状态与字符数可见。原Journal接口及旧手记迁移保持不变。

## 补齐 preview.5

保留用户提供的卡通头像日期标志、首页无箭头/圆点的滑动相册、季节文字色。补齐触感强度、音乐和系统时钟原生桥接。QQ优先，网易云其次，无法处理时给官方网页或复制歌名的明确提示；单曲需核对，不承诺自动播放。系统时钟仍需用户确认时间、铃声和振动，不伪称已经设好闹钟。

## 验证边界

以最终交付的Actions run、APK SHA-256、证书比较和验证资料为准。此前Android 11模拟器在四季切换回归中出现过渲染进程中断，Android 15慢启动走过兼容开屏路径；本次返回与手记改动不能自行消除这些已知风险。实体手机震感、第三方QQ/网易云客户端、长时间稳定性及全部厂商系统尚需实机验证。未通过的检查不能当作通过交付。
