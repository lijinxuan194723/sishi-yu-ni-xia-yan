# 2.0.1-preview.6 · 返回衔接与手记细节

候选版本 2.0.1-preview.6 / 902006，基于最后交付的 preview.4，整合此前未发包的 preview.5 代码。代码位于 fix/rounded-native-startup，正式 main 不变。最终以签名 APK 内实际版本为准。

## 本轮实现

后台停止后再进入，使用独立的轻量圆章淡出，不重建 WebView、不重新载入页面、不缩放正文。页面绘制回调和 120ms 回退都可以启动 280ms 淡出，650ms 清理保险；退出、销毁、渲染进程终止均移除覆盖层。系统关闭动画时直接恢复。从音乐、系统时钟和文件选择器返回不重复播放这段过渡。此策略改善衔接，不承诺掩盖所有硬件卡顿。

主题图片解码复用；同一分钟、同一主题和光照设置不重复发布页面状态，避免 focus 和 visibilitychange 同时触发重复的大图准备和重新渲染。

手记由一排小图标改为圆角操作面板。短按编辑，480ms 长按或可见的更多按钮整理。手指移动、滚动、取消、切后台会取消未触发的长按。长按后的合成点击只吞一次，不影响键盘或其他笔记。面板支持置顶、加星、移动、复制、导出、多选；回收站独立且需要确认；非永久删除。列表渲染节点稳定，正文两行摘要，元信息单独排版；编辑器标题和正文留出空间，状态栏反映真实本机保存结果。

## 补齐 preview.5 原生接入

保留提供的卡通头像日期标志、首页无箭头/圆点的滑动相册、季节文字色、手记装饰。补齐触感强度、音乐和系统时钟桥接。QQ 优先，网易云其次，不能处理时给官方网页或复制歌名的明确提示；歌曲匹配需要核对，不承诺自动播放。系统时钟需要用户完成时间、铃声和振动确认，本应用不伪称已经设好闹钟。

## 验证要求

逻辑检查、精确 APK 的浏览器测试、Android 运行结果必须分别报告。新增笔记真实触摸长按、操作面板尺寸、删除取消、保存和覆盖安装检查。以最终交付的 Actions run、APK SHA-256、证书比较和验证资料为准。此前 Android 模拟器渲染进程中断尚不能仅凭源码修改宣称解决；实体手机的震感、第三方 QQ/网易云客户端和所有厂商系统尚需实机验证。
