# 四时与你 · WebView 2.0.10 功能修订版

这是完整 WebView + React 工程，包含功能代码、图像、静态年度数据、依赖锁文件、Android 原生壳、打包入口和本轮检查。不是仅修改头像的补丁，也不是 Compose 迁移工程。本版版本号 2.0.10，Android versionCode 902060。

## 基线和交付范围

本轮实际可核验的起点是 GitHub 2.0.5 完整归档，加上已经核验的配置兼容修改。未取得可核验的原始完整 2.0.9 ZIP，因此不把本工程宣称为原 2.0.9 的逐字节恢复。针对用户此前要求的功能，重新接入了四年节假日、玻璃外观、双方独立外观、科目管理、分区以及本轮的新功能。原人物素材和已有数据键尽量保留；字段兼容和具体检查见 reports/baseline-comparison.json。

本轮没有写入 GitHub；此前写入安全限制没有通过其他接口规避。主线、原生迁移分支均未改变。代码内的 GitHub 地址仅作仓库参考，不表示此版本已同步。完整源码以本轮 ZIP 为准。

## 必须明确的运行边界

当前容器无法在原产品网络策略下完成本地HTTP页面验证。浏览器测试明确加载本轮生产JS/CSS到about:blank，使用MemoryStorage、模拟Android网络桥与受控模型/天气/GitHub/节假日响应；不是CSP、真实IndexedDB、系统杀进程/断电、原生输入法、相册或网络服务质量验收。APK真实构建和签名成功不等同于真机安装/升级测试。本轮没有实体手机120Hz帧率、耗电或系统通知表现结论。

天气只使用Open-Meteo，没有复制Smartisan项目的小米客户端签名，也没有复制其原版位图/音效。Skills安装的是可供聊天参考的方法与文本资料，不是手机命令执行器、MCP、Root/无障碍或第三方APK安装器。所需脚本资源被记录为未执行；不把这个范围称作完整Eta运行时。

应用内拖尺采用持久化结束时间恢复倒计时，页面回到前台时补算；不是Android常驻精确闹钟。需要锁屏/关闭应用后的可靠响铃时，在保留的「夏彦的提醒便笺」中到系统时钟确认，提醒受用户系统设置约束。修改设备墙上时间仍可能影响网页倒计时，不将其描述成Smartisan原生单调时间实现。

真实模型可能遗漏、输出不准确或拒绝服务；原文和失败状态保留，不能声称「永远全部记住」或「绝无任何问题」。未知节假日不得推算；主界面按用户要求减少来源文字，提供方许可仍需要公开分发时核对，尤其Open-Meteo署名位置。

## 安装和源码

随本轮提供的APK为独立包名 **com.luke.summer.webview210**，桌面名 **四时与你·WebView**，新独立签名。不会覆盖旧版，也不会自动带入旧聊天。保留旧版，在旧设置中先导出完整备份，确认文件保存，再到新应用导入；模型Key需重新设置。不要用卸载或清数据解决签名问题。新应用自行产生数据后再导入会替换当前存档，先备份。

源码默认包名仍com.luke.summer。按BUILD-WebView-2.0.10.md重新构建；要做旧包名覆盖必须使用对应旧签名。完整工程不带node_modules、SDK、私钥、字体二进制或用户记录。依赖来自已固定的离线工具归档，本轮未重新联网执行npm ci，Windows包装命令只做静态检查，未在Windows实际运行。
