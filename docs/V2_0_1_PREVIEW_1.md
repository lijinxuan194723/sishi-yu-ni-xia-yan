## 本轮改进

1. 桌面名称改为“四时与你·预览”，npm、Android 与应用内版本标识统一；versionCode 比上一预览包递增。
2. 修复自定义聊天背景没有接入最终聊天样式的问题：保留随昼夜变化的文字保护遮罩，自定义图片可覆盖季节图片，重启自动恢复；恢复默认只删除背景键。
3. 背景图片支持 JPG / PNG / WebP，输入上限 8 MiB；最长边压缩到 1440 像素，处理结果限制 150 万字符，避免大图直接挤占存储。已有合法 GIF 背景仍可读取。
4. 增加图片预览、处理状态、恢复季节背景、格式/大小/解码/超时/存储错误反馈。保存成功前不切换背景；快速重新选图与关闭设置会取消过期处理。
5. 独立聊天视口按半像素归一化，同尺寸事件不重复更新输入框；区分双指缩放与软键盘，前台恢复时重新测量；监听器与动画帧在卸载时清理。
6. 新的外观操作、版本卡片延续圆角、季节配色和至少 44px 操作高度，并支持减少动态效果。

## 安全与兼容

没有修改正式应用包身份、WebView origin、聊天/笔记存档键、模型配置、网络权限、签名配置或 CI 工作流。预览工作流会使用 com.luke.summer.preview，与正式版并存；不要卸载正式版。能否覆盖上一预览包必须以本次构建后的签名证书与版本号比较为准，不能只依据源码声明。

依赖版本不变；沿用上一成功构建的依赖锁文件。锁文件保留历史根包版本元数据，该字段不是 APK 版本。依赖审计告警不是本轮已解决项。
